# 领域边界

管理数字贸易项目的沙盒准入、跨境数据边界、规则版本和争议保全。

现有领域资料围绕以下边界组织：

- 项目与主体
- 数据合规判定
- 沙盒试运行
- 风险整改退出
- 争议保全与裁决

资料版本只能递增。参与方、事实和约束均不能为空，示例不得包含真实个人信息、账号或凭据。

## 后端实现的不变量（`src/sandbox/`）

- **材料**：十类材料分阶段补交、版本递增；批准决定钉住决定时刻的规则版本与各材料版本号，决定后修订只追加不改写。
- **评审**：辅导关系、利益关系、申请方本人一律强制回避；职责范围不符不能评审；存在反对意见不得批准。
- **秘密**：商业秘密材料按"材料类别→审查职责"对照表限定可见范围，须职责相符且获专项授权。
- **批准**：边界五要素（数据范围、持续时间、用户规模、监测指标、退出条件）缺一不可；名额在批准事务内占用。
- **运行**：用途扩张缩限、超限整改、事件暂停、合作方退出/条件成就退出；暂停记住前置阶段；原批准决定任何路径下都不删除、不覆写。
- **容量**：退出生效、名额释放、操作链记录同事务；中途失败整体回滚。
- **规则**：批准钉住版本；规则更新不回溯作用于在运项目，只适用于此后新决定。
- **争议**：提出即把材料集合、访问名单（含已撤销授权）、操作链截取点同事务固定；未决争议材料封存；裁决渠道（调解/仲裁/诉讼）与结果（恢复/调整/维持退出/维持现状）均记录；调整以修订单另存，原批准保留。
- **中断**：业务时钟冻结期间不流逝业务时间；跨期的整改期限按中断时长顺延，中断证据随项目保存。
- **留痕**：全部状态变更进入哈希链操作记录，链可随时复核；主管视图汇总边界、阶段、期限、风险、争议与停机证据。
